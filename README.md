# 하루의 구글시트 연구실

구글시트의 원본 → 처리 → 결과를 데이터 테이블로 설명하는 한국어 HTML 교재입니다.
학습 순서: **SECTION 09 → SECTION 08 → SECTION 07 → SECTION 10**.
목차 1개, 챕터 11개, 학습 항목 67개, 추가 예제 201개를 포함합니다.

## 시작

[전체 목차 열기](index.html)

압축을 푼 폴더의 `index.html`을 엽니다. GitHub Pages의 기본 진입 파일도 소문자 `index.html`입니다. `INDEX.html`로 이름을 바꾸면 기본 진입 경로가 달라질 수 있으므로 사용하지 않습니다.
각 챕터의 실습 코드는 자체 HTML에 포함되어 별도 설치·서버·빌드·CDN이 필요 없습니다. 표지 삽입 후에는 `assets/covers/`도 함께 보관·게시합니다.

## GitHub Pages 게시

1. ZIP 자체가 아니라 압축을 푼 **내용**을 저장소 루트에 업로드합니다.
2. 루트에 `index.html`, `section-*.html`, `README.md`, `docs/`, `assets/`, `cover-manifest.json`을 함께 둡니다.
3. 저장소 Settings → Pages에서 업로드한 브랜치와 루트 폴더를 게시 대상으로 선택합니다.
4. GitHub가 제공한 실제 Pages 주소로 접속합니다. 사용자명·저장소명이 제공되지 않아 이 문서에 공개 주소를 임의로 만들지 않았습니다.
5. 파일명 대소문자를 그대로 유지합니다. 모든 내부 링크와 표지 경로는 저장소 하위 경로에서도 쓰도록 상대 경로로 작성했습니다.

GitHub 업로드·게시 작업은 사용자가 직접 진행합니다.

## Genspark 표지 제작 → HTML 삽입

각 표지는 1280×1280, 정사각형 1:1입니다. 목차 1장과 챕터 11장, 총 12장입니다.

1. 별도 프롬프트 묶음의 `references/` 캐릭터 4장을 첨부하고 `prompts/`의 해당 지시문으로 표지를 제작합니다.
2. `cover-index.png`, `cover-09-01.png`처럼 정해진 파일명으로 저장합니다. JPG·WebP도 같은 stem으로 받습니다.
3. 이미지 12장을 ZIP으로 묶어 하루에게 전달합니다. 일부만 먼저 전달해도 해당 페이지부터 반영할 수 있습니다.
4. 하루가 `cover-manifest.json`에 따라 대상 HTML을 확인하고 표지 이미지·alt·width·height를 삽입합니다. WebP 배포본과 원본을 구분하고, 1:1 전체 이미지가 잘리지 않도록 표시합니다.
5. 기존 본문·표·수식·퀴즈를 유지하고 목차·표지 경로·파일 묶음을 갱신합니다. 화면 검수는 사용자 지시에 따라 생략합니다.

현재는 **목차 1장·챕터 11장, 총 12장 표지 삽입 완료** 상태입니다. 사용자 제공 1280×1280 WebP 원본을 재압축하거나 자르지 않고 `assets/covers/`에 배치했습니다. HTML과 assets 폴더를 함께 업로드하세요.
표지 파일명과 HTML의 정확한 대응은 [cover-manifest.json](cover-manifest.json)에 있습니다. 개별 지시문은 `docs/COVER_*.md`에도 있습니다.
이미지에는 제목·글자·숫자·수식·로고를 그리지 않고 제목은 HTML로 표시합니다.

## 실습과 검증

- 추가 예제의 입력은 새 구글시트 A1부터, 출력은 H열부터 사용하는 독립 실습입니다.
- 원본 완성예제 66개의 읽은 값과 실제 링크를 보존했습니다. 원본 표는 앞 14행까지 표시하며 원본 셀 주소·수식은 링크에서 확인합니다.
- 지점명은 A지점·B지점·C지점으로 통일했습니다.
- 신규 201개 중 150개 수식 예제를 실제 구글시트에서 검사했습니다. SPLIT의 숫자 자료형 3건을 교정하고 재검사했습니다.
- 실제 메뉴·나머지 외부 연동 51개는 미검증입니다. 실제 화면 검수는 사용자 요청으로 생략합니다.
- 날짜·난수·주가·번역·웹 데이터 결과는 실행 시점·권한·제공 서비스에 따라 달라집니다. HTML은 설명용 재생 화면이며 구글시트 엔진 자체가 아닙니다.
- 기능·링크·온톨로지 꾸러미 검사 결과와 범위는 [docs/QA.md](docs/QA.md), 실제 수식 검사 기록은 [docs/native-formula-results.csv](docs/native-formula-results.csv)에 있습니다.
- 브라우저 저장소·쿠키를 쓰지 않으며 연습 상태는 새로고침하면 초기화됩니다.
