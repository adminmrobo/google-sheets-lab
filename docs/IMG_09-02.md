# 순위·반올림과 문자열 다듬기 · 이미지 제작 명세서

| 항목 | 내용 |
|---|---|
| 앵커 | D: 구글시트 업무 공간 |
| 시즌 | 기본 밤의 연구실 |
| 기존 그림 | 사용자 제공 character_pack, commit ea5da3f4d73877c7bef4238327f59b6cb72129f6 |
| 표지 | 네 캐릭터 CSS 대체 표지 완료. COVER_09-02.md에 선택형 제작 프롬프트 제공 |
| 본문 삽화 | 없음. 실제 표와 처리 단계로 설명 |
| 행동으로 보기 | 코드 기반 행 카드 |
| 아웃트로 | 기존 캐릭터 4명 재사용 |

## 일관성
새 캐릭터를 그리지 않고 패키지의 표정 매핑을 사용한다. near/missing 매핑은 원본 expression_map.json의 근사/기본 표정 정책을 따른다.

## 넘겨받은 뒤 처리
새 표지를 받으면 비율·네 캐릭터·안전 영역을 확인하고 WebP로 압축한다.

## 표지 규격 변경
사용자 지시에 따라 1280×1280, 1:1 정사각형. 각 COVER 파일과 루트 cover-manifest.json이 최신 표지 사양이다. 목차와 챕터 표지 12장 모두 사용자 제공 WebP 삽입을 완료했다.
